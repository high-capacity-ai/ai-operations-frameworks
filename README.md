# ai-operations-frameworks

Sanitized multi-agent operating topologies, governance patterns, and delivery architectures from High Capacity AI.

## What lives here
Principles, topologies, architecture decision records, and governance patterns for running evaluated AI work lanes inside a managed-services operation — published as versioned releases.

## What never lives here
System prompts, model parameters, evaluation datasets, QA scoring scripts, infrastructure specifics, unit economics, or client material.

## Status
The first release publishes the functional-unit operating topology for service delivery.
